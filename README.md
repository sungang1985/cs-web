# 破晓行动 · Daybreak Ops

一款原创的网页版第一人称战术射击游戏：5v5 回合制团队歼灭、经济与购买系统、电脑 AI 队友和对手。
纯前端实现（Three.js + WebAudio），贴图、模型、音效全部由代码程序化生成，无需任何素材文件或构建步骤。

## 运行

游戏使用 ES Module，需要通过 HTTP 访问（不能直接双击打开 `index.html`）：

```bash
python3 -m http.server 8000
# 然后用桌面浏览器打开 http://localhost:8000
```

也可以直接部署到 GitHub Pages 等任意静态托管服务。需要键盘和鼠标，暂不支持触屏。

## 操作

| 按键 | 功能 |
| --- | --- |
| W A S D | 移动 |
| 空格 / C / Shift | 跳跃 / 蹲下 / 静步 |
| 鼠标左键 / 右键 | 开火 / 狙击枪开镜 |
| R | 换弹 |

| F3 | 显示帧率与实际渲染分辨率 |
| Esc | 暂停 |

## 规则

- 歼灭对方全员赢得回合，先赢 8 个回合的队伍获胜；
- 击杀、回合胜负都会获得资金，用于购买武器、防弹衣和弹药；
- 存活到下一回合可保留武器，阵亡后只剩手枪；
- 阵亡者的枪会掉在地上：没有主武器时走过去自动拾取，已有主武器时按 E 更换；
- 跑动有脚步声，电脑能听见；静步和蹲行无声；
- 爆头造成 3 倍伤害，移动、跳跃和连射会降低精度，蹲下更准。

## 目录

- `index.html` — 页面与 HUD
- `src/map.js` — 地图、碰撞、射线检测、A* 寻路
- `src/textures.js` — 程序化贴图（颜色 + 法线）
- `src/models.js` — 武器与角色模型、持枪 IK、行走与倒地动画
- `src/audio.js` — 预渲染枪声与音效
- `src/settings.js` — 画质档位
- `src/game.js` — 渲染、武器、AI、回合流程
- `vendor/` — Three.js（MIT 许可）

## 性能说明

- 静态场景按材质合并为 5 个网格，阴影贴图只渲染一次；角色使用贴地软阴影；
- 弹孔、曳光、烟尘、枪口火焰全部池化，着色器在开局时预编译；
- 枪声预先渲染为音频缓冲，并限制同时发声数量；
- 电脑寻路使用二叉堆 A*，听到枪声后的重新寻路带冷却；
- 菜单可选低 / 中 / 高三档画质（默认中）。各档都有渲染像素上限，高分屏不会按原生分辨率渲染；
- 持续帧率不足时自动降低渲染分辨率（只降不升，避免来回切换）；
- 开镜遮罩由着色器绘制。
